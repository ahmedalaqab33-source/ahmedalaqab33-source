## Research software

### [Clinical Data Analysis Pipeline](https://github.com/ahmedalaqab33-source/clinical-data-analysis-pipeline)

A reproducible Python workflow for clinical-research CSV data quality checks and descriptive summaries.

- **Methods:** transparent preprocessing, missingness and duplicate checks, descriptive reporting.
- **Engineering:** Python, pandas, pytest, Ruff, GitHub Actions and documented reproducibility.
- **Scope:** descriptive research analysis; clinical application requires additional validation.
